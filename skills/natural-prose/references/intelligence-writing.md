# Natural Prose · 情报与产品动态

> 用于 AI 情报、新闻、产品发布、公司动态、模型更新和单事件行业稿。

## 1. 默认结构

情报稿优先沿事件本身推进：

```text
发生了什么
→ 具体改了什么
→ 当前理解需要的背景
→ 关键数字 / 机制 / 口径
→ 对实际使用的影响
→ 证据缺口 / 未知项 / 下一观察点
```

这是一条可能的语义链，不是必须逐项出现的目录。

## 2. 连续正文规则

`continuous_editorial` 默认：

- 不写 narrative H2；
- 不用 H3/H4、`01 PART`、单行粗体短语、`写在最后` 等伪标题；
- 不把“背景 / 核心变化 / 影响 / 怎么看”当固定章节；
- 每次只补当前事件链真正需要的信息。

### 事件先于意义

第一屏尽快出现谁、什么时候、做了什么、关键变化是什么。

不要先写“AI 行业又迎来重大转折”。

### 背景随用随补

解释价格时补历史价格；解释商业模式时补付费结构；解释组织调整时补相关团队变化。

背景是正文零件，不是固定章节。

### 数字后补口径

数字出现后，优先判断是否需要说明：

- 与什么相比；
- 时间范围；
- 是岗位编制还是实际人数；
- 是标称值还是实测值；
- 对成本、速度、使用有什么后果。

不要只扔一个传播性数字。

### 评论只做四件事

1. 解释数字的实际后果；
2. 指出官方说法缺少什么证据；
3. 帮读者比较两条实际路径；
4. 说明现在还不知道什么。

评论不要自动升级成行业终局。

## 3. 对象切换

从公司 A 切到公司 B 时，如果 B 正在回答 A 留下的问题，可以直接切换。

```text
OpenAI 选择用广告补免费用户收入。Claude 走的是另一条路，目前仍把无广告当作产品承诺。
```

不需要写“接下来把视角转向 Anthropic”。

对象完全独立时，按调用者的合集格式处理；不要自行创造叙事型 H2。

## 4. 自然结尾

优先停在：

- 最新状态；
- 能确认到的证据边界；
- 对某类用户的实际选择；
- 下一项真正值得观察的数据或发布。

例：

```text
现在能确认的是 API 已开放、价格已经公布，稳定性数据还很少。要不要迁移，至少等第一轮生产环境数据出来再判断。
```

正文没有持续处理时代尺度，就不要在末段突然写时代、文明、终局。
