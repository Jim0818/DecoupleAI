# Natural Prose · 自然推进参考

> 仅在正文卡住、相邻句段接不上或 Reviewer 需要判断“有没有真的往前走”时加载。

## 1. 核心模型：局部语义接力

连续正文不靠目录维持方向，而靠相邻内容之间存在可解释关系。

内部只问：

1. 上一句刚交出了什么对象、结果、问题或判断？
2. 读者此刻最需要补的是哪一种内容？
3. 下一句能不能直接完成这件事？

不要把这三个问题写进正文。

局部接力不排斥适量口语。“但”“所以”“先看这个问题”“说到这里”只要准确交代转折、结果或当前任务，就比抽象路标更顺口。连接词不是配额，同一个词自然重复也无需强行替换。

## 2. 十个推进动作

### P1 对象续接

**用途**：同一对象还没处理完。

```text
模型现在支持 256K 上下文。这个变化对长文档任务最直接，因为过去需要先切块的输入可以一次送进去。
```

不要因为担心重复，不断把“模型”改成“该系统 / 这款产品 / 这一技术方案”。普通指代更自然。

### P2 结果补因

**用途**：读者已经看到结果，下一步想知道为什么。

```text
批处理时间从 42 分钟降到 19 分钟。主要原因不是单次调用更快，而是失败重试少了很多。
```

不必先写一整节背景再到结果。

### P3 抽象落地

**用途**：出现“更适合、更稳定、更便宜、更难用”等判断。

```text
它更适合批量抽取。我们这里一次要处理 300 份文档，而且宁可漏一条，也不能编一条不存在的字段。
```

抽象判断如果长期没有任务、数字、动作或后果承接，就是悬空。

### P4 定义随用随补

**用途**：术语第一次真正影响理解。

```text
这里用到的是 speculative decoding。简单说，就是先让一个小模型提前猜一段 token，再由大模型一次校验。
```

不必把所有术语提前放进“背景知识”。

### P5 例子承担证明

**用途**：机制或判断需要一个可观察结果。

```text
这个限制在长 JSON 上很明显。字段一多，模型偶尔会把后半段截掉，所以输出长度不能只看平均值。
```

例子必须改变理解，不为了“生动”而加。

### P6 具体问答

**用途**：存在真实认知债务。

```text
为什么这次价格降了，实际账单却没明显变？因为请求量同时翻了接近一倍。
```

问题必须马上回答。不要用宏大设问制造气氛。

### P7 评论贴证据

**用途**：证据已经足够，读者需要一个选择或解释。

```text
三组任务里它都更便宜，但长文本失败率高一些。只做摘要我会选它，结构化抽取暂时不会。
```

评论最好解决一个具体判断，然后离开。

### P8 限制回压

**用途**：正面结果容易被读者扩大理解。

```text
官方给出的成功率很高，不过公开材料没有说明失败样本集中在哪些类型。现在还不能把这个结果直接外推到复杂工具调用。
```

限制不是“优缺点必须平衡”，而是确实影响结论。

### P9 允许密度不均

**用途**：材料本身重要程度不同。

普通背景一句带过；关键机制、代码、实验可以连续多段。不要为了视觉整齐把五个部分写成相同长度。

并列比较、互不依赖的操作步骤和可替换模块可以保持并列。段落互换后仍成立只是诊断线索；如果每段承担不同职责，就不要为了制造“推进感”硬写成因果链。

### P10 停止

**用途**：读者任务已经完成。

结束前只检查：

- 关键事实是否交代；
- 机制或步骤是否讲清；
- 必要限制是否写出；
- 需要做选择时是否已有有边界结论。

都满足就停，不再补“总结全文”。

## 3. 常见断裂与修复

### 断裂 A：上一段讲结果，下一段突然讲行业

**坏写法**

```text
测试里延迟下降了 18%。

从更大的视角看，这其实代表 AI 基础设施正在进入新的阶段。
```

**修复**

```text
测试里延迟下降了 18%。这个变化主要出现在长请求，短请求几乎没区别。
```

先处理当前结果，不自动换尺度。

### 断裂 B：背景章节提前出现

**坏写法**

```text
先介绍一下向量数据库的发展历史……
```

正文真正的问题只是为什么当前检索结果会过期。

**修复**：等解释“旧 embedding 为什么残留”时，只补当前需要的索引更新机制。

### 断裂 C：段落靠主持人口吻连接

**坏写法**

```text
说完性能，我们再看看价格。
```

**修复**

```text
性能差距不大，真正影响这次选择的是调用量。按目前每天 2 万次请求算，价格差会被放大。
```

如果“说完 A，再看 B”只是导航，通常可以让 A 的结果直接引出 B。

## 4. 不要把接力做成模板

不要固定循环：

```text
事实 → 解释 → 例子 → 评论
事实 → 解释 → 例子 → 评论
```

真实文章可以是：

```text
事实 → 事实 → 结果 → 原因 → 机制 → 机制 → 例子 → 限制 → 下一事实
```

推进动作由材料决定，不由段落模板决定。
