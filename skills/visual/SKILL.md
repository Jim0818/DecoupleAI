# 视觉制作与图文交付

每次内容生产都应用本方法。主管、写作、审阅按下表承担相应责任；实际绘制可以由主管或视觉员工完成，不要求增加固定串行阶段。完整新稿不能因没有显式“配图”指令而跳过。数量按解释需要决定，不按 H2、字数或来源数凑图。

## 按任务范围使用

| 方法模式 | 本次工作 |
|---|---|
| `assess`（主管） | 核对正文目标、已选来源、已有图片与实际可调用工具；落实执行者、插入位置、图片输出和完成条件。 |
| `integrate`（写作） | 将真实图片、图注和来源放在对应论证段落；取不到图时保留可见的具体待补图块。 |
| `review`（审阅） | 核对图片实际存在、图文相符、来源和证据身份正确；缺图必须报告，不能靠删提示获得通过。 |
| `preserve`（标题/摘要等局部任务） | 检查本次变化是否影响原图含义、图注和引用；未受影响的资产沿用，不擅自重画或扩大写范围。 |
| `create / revise / export`（视觉执行） | 读取[路由与交付](references/routing.md)，实际生成、取图、修图或导出，检查后提交。 |

`assess / integrate / review / preserve` 只读本页及实际触发的分支，不预加载全部模板、工具说明和研究资料。用户明确限制为纯文字或仅改局部时服从本次范围，仍核对受影响图文。系统维护和技能更新不为了证明调用而给无关内容配图。

## 三条必须落实的取图路径

1. **原创插图**：完整新稿或需要重做插图时，当前会话有实际可调用的原生生图工具，就使用它生成与正文有关的插图，并查看成图。依据真实工具列表判断能力，不凭模型名称、已安装 Skill 或第三方 API 包推断。不能只交提示词，不能用 HTML 卡片冒充模型插图。原生工具无法调用或执行失败时，写明真实原因；仅使用已有且获准的替代能力，不编造成功。
2. **架构与结构关系**：架构图优先使用用户已有的 `~/.claude/skills/archify`，执行[Archify 接入](references/archify.md)。精确数据、坐标轴、架构连线和代码事实使用确定性工具；模型插图不能替代这些结构或实验结果。
3. **论文、网络文章和博客**：凡正文引用其内容，查看原文中相关图及图注，优先取得可复用原图，其次忠实截图。按[来源图与人工补图](references/source-figures.md)记录真实位置与来源；不能仅提炼文字后用无关插图补位。未取到时，在正文相应段落后明确请求用户补图。

已有真实截图、论文图、官方图按原始身份保留。原创概念图明确标为示意，不充当“我实测过”、真实 UI、实验数据或原作者提供的证据。

## 正文集成与缺图

- 写作和视觉执行者围绕同一成果版本协作。图片随任务在 staging 生成，再由主管按现有 submit 晋升；图像正式路径与正文相对引用必须匹配。
- 原图引用带简明图注和来源链接；必要时注明图号、页码或所在小节。来源位置未核实就说未核实，不猜造。
- 无法生成、下载、截取或复用时，按 source-figures reference 在**正文对应位置**留下 `> 【待补图｜类型】`，写清来源、要取什么、可核实定位、建议图注和失败原因。不能只放在文末清单或发布元数据。
- 没有实际图片时不写伪路径、空图片标签或“已完成”。有待补项可交付可审阅草稿，并在最终说明中点明待补；不能声称图文齐备或可直接发布。补齐真实资产、核对图文后才删除提示。

## 视觉规格与验收

采用当前账号和用户指定的视觉要求。共用细则在[视觉设计系统](references/visual-design-system.md)；选择图形结构时按需读[布局](references/figure-layouts.md)，选择原创插图美学时按需读[风格示例](references/style-library.md)。采用现有 SVG renderer 才加载[SVG 构图与复检](references/svg-composition.md)，不预读模板。原创微信封面默认 47:20、印象派水墨风、无文字/Logo/人物、至多三类主色、留白充足；正文证据图保留必要标签、坐标轴和图例。

查看实际输出，检查文字、裁切、连线、清晰度、比例和移动端可读性。渲染器校验通过只证明自动检查通过；未看图不得声称视觉验收。发布端不能渲染 HTML/Mermaid 时导出真实图片，源码和提示词不是插图完成证明。

直接交付实际图片、必要可编辑源文件及已更新的正文或精确插入位置。沿用现有任务结果记录所选工具、来源、位置和未解决项，不另增固定蓝图、配图报告或提示词数量。外部能力的调研和适用范围见[工具来源](references/tool-sources.md)，仅在选择或维护工具时读取。
