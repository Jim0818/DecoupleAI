# 视觉制作

先明确这张图帮助读者理解什么：真实数据比较、结构关系、事件顺序、操作结果，还是封面主题。若没有视觉增量且用户未要求，不为凑数量出图。

按 [路由与交付](references/routing.md) 选择一种最合适的表达。现有模板在 `assets/templates/`；需要布局参考再读 `references/figure-layouts.md`，需要视觉细则再读 `references/visual-design-system.md`。只读取当前选择的部分，不全量加载模板库。

- `create`：依据已选内容、事实与规格创建资源。
- `revise`：只修改指定图及其相关标注，保留未涉及内容；事实变动交主管确认关联影响。
- `export`：将已有源文件转成用户需要的格式，不重新设计或复制一套素材。

使用任务允许的输出位置。保留必要源文件与实际交付文件；同一图不默认同时做 HTML、SVG、Mermaid、PNG。需要图像生成时使用已提供的图像能力，不能用提示词文件假装已生成图片。

图中的数字、对象、关系、时间和版本遵守正文证据边界。实拍截图、官方图、自制示意图和概念演示分清身份。插图位置按对应事实或段落确定，不按 H2 数量机械分配。

渲染后用可用工具检查文字溢出、裁切、箭头、字体和比例；实际未渲染时说明交付是源文件，不声称通过视觉检查。回传资源引用和必要用法，不生成无消费者的图形自检长报告。
