# 图形布局与支持范围

仅在选择图形结构或检查构图时加载。布局表达概念关系，风格控制美学，工具承担实际制作；三者按用途组合。架构图按 [路由](routing.md) 优先 Archify，不能因为某布局能渲染就覆盖用户指定能力。

## 项目 SVG renderer 的六种布局

字段和允许值以 `config/contracts/content/svg-figure-spec.schema.json` 为准；当前渲染入口为 `PYTHONPATH=src python -m textpicos.rendering.render_svg_figure`。下面六类均为 `renderer_status=supported`，表示已有实现，成图仍须查看。

| layout | 概念与适用范围 | 视觉语法 |
|---|---|---|
| `layer_stack` | 架构、能力、协议等分层关系 | 纵向层叠，突出递进与主层，避免平均堆块 |
| `pipeline_flow` | 输入、处理、输出和低分叉执行链 | 可追踪主路径，低交叉连线 |
| `decision_tree` | 条件分流、方案取舍 | 根节点、带条件的分支、明确结果 |
| `mechanism_explainer` | 组成、因果、约束与机制解释 | 中心机制和必要周边关系，避免关键词拼贴 |
| `before_after` | 改造、纠错或方案变化 | 共享对比轴，突出变化点，两侧密度合理 |
| `comparison_matrix` | 少量对象和少量维度比较 | 行列对应，重点有限；文字密集时改表格/HTML |

使用 [SVG 构图与复检](svg-composition.md) 形成 Spec，样式只取 [视觉设计系统](visual-design-system.md) §11 的令牌。渲染结果拥挤、难读或关系不清就修构图或选择更合适工具。

## 其他概念表达

以下是选图词汇，不是 SVG API 别名，也不代表已实现的新模板。实际能力以当前工具和模板为准；未实现时不预造渲染器、不手写不受控 SVG。

| 概念结构 | 识别信号 | 表达方式与当前选择 |
|---|---|---|
| 双对象对比 | 同一维度下比较两个对象 | 对称栏或并置；简单结构可用 before_after，密集内容用 HTML |
| 线性推进 | 无分叉的顺序、步骤或演进 | 可追踪链路；架构用 Archify，轻量草图用 Mermaid |
| 层级展开 | 由上到下或从基础到应用逐层深入 | 水平带、缩进或层叠；按语义选树形图或 layer_stack |
| 中心辐射 | 一个核心与并列组成，无先后取舍 | 核心与必要放射关系；简单机制用 mechanism_explainer |
| 结构拆解 | 部件、文件结构、组成标注 | 主体加引线；代码/密集标签用 HTML |
| 树形分支 | “选哪条”或目录从属关系 | 条件分支与目录从属分开表达；决策可用 decision_tree |
| 漏斗 | 逐级筛选、数量收窄 | 宽度随真实数量变化，注明筛选理由；当前用已支持的图表或 HTML |
| 路线图 | 一条路上的阶段与里程碑 | 清楚方向、节点与真实时序；按实际能力选 Archify/Canvas/手绘 |
| 冰山 | 可见现象与隐藏机制二分 | 明确表层/深层含义；原创概念图或合适确定性工具，不冒充数量关系 |
| 速查卡 | 可独立阅读的少量要点 | 网格或条目；使用已存在 HTML/ui-view 模板 |
| 多维矩阵 | 多对象、多维度比较 | 表格或 HTML；低密度时才选 comparison_matrix |
| 循环反馈 | 返回起点的反馈或闭环 | 关系方向和反馈条件明确；Archify 或 Mermaid |
| 仪表盘 | 多个实际指标并置 | 分区指标和单位；HTML/确定性图表，不编造数据 |

## 容易混淆的选择

| 判断 | 应选结构 |
|---|---|
| 有条件取舍，而非单纯并列组成 | 决策分支 |
| 并列组成，没有先后 | 中心辐射或分组 |
| 顺序推进，没有选择分叉 | 线性推进或路线图 |
| 筛选使数量递减 | 漏斗 |
| 信息逐层展开，而非数量淘汰 | 分层 |
| 强调可见部分与隐藏机制 | 冰山概念 |
| 只比较两个对象的一个变化 | 并置对比 |
| 多对象在多个维度比较 | 矩阵或表格 |

漏斗宽度应有真实数量依据；没有数量就表达条件链，不制造精确视觉。冰山不默认说明“隐藏部分占多数”，须有材料或明确示意。速查卡只放可用要点，不额外制造每节小结。

本文件由视觉方法和员工按需消费。布局选择落在当前任务的图片与必要源文件中，不要求单独蓝图、固定候选数或新增输出契约。
