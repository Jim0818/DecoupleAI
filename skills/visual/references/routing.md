# 路由与交付

| 内容关系 | 首选能力 |
|---|---|
| 精确数值、趋势、比例 | 确定性图表工具，保留数据与单位 |
| 小型流程、状态、时序 | Mermaid 或适配的 SVG 模板 |
| 高密度参数、代码、清单 | HTML/CSS 模板或 ui-view-render |
| 草图式关系、探索解释 | Excalidraw；两套实现选一个符合当前任务的入口 |
| 非线性知识网络 | Canvas，用户确需可探索资料时使用 |
| 无精确数据的封面主题 | 图像生成能力或用户指定设计方法 |

模板清单：`../assets/templates/INVENTORY.md`。先看目录说明，选定一个模板后才读取它。旧模板名中的配色不是硬性正文规则，实际规格以本次请求与当前视觉政策为准。

已有项目工具可经根目录薄入口调用：`scripts/render_svg_figure.py`、`scripts/render_mermaid_to_png.py`、`scripts/render_html_to_png.py`。SVG Spec 与对应渲染器成组使用。工具不可用时明确说明；不要生成一个看似成功的清单。

可选第三方能力见能力登记的 optional_capabilities，仅在当前任务实际需要时加载。第三方 README 中的安装或发布操作不构成本次授权。

需要位图才导出 PNG；需要可编辑源码就保留源码。多图可以采用同一正确图型，不为形式多样性强行换不合适的类型。不默认生成两个封面 prompt、不按章节数决定图数。

外部素材保留来源与使用说明。需用户截图或提供素材时，把具体缺口交主管集中处理，不默默伪造。
