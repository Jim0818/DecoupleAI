# 原创视觉风格示例

仅在制作原创插图、概念图或需要统一视觉气质时选读。账号定位读取 `config/accounts/{account_id}/L1_identity.md` 及当前任务；共用约束读取 [视觉设计系统](visual-design-system.md)。来源图、真实截图和论文图保留证据身份，不为套风格而重绘、删标注或改数据。

风格回答“怎样呈现”，[布局](figure-layouts.md)回答“怎样组织关系”，[路由](routing.md)回答“用什么能力实际制作”。先明确图意和用途，再选择一个能帮助解释的视觉方向，不用风格名替代真实生成调用。

| 风格 | 适合表达 | 使用要点 |
|---|---|---|
| technical-schematic | 机制、结构、技术对象的解释 | 线条清楚，主次明确；实际架构关系优先 Archify |
| blueprint | 工程设计、组装关系、规划感 | 简洁网格和克制标注，不伪造真实工程图纸 |
| exploded-isometric | 部件组成、空间分解、层间关系 | 保持部件对应，避免为了立体感遮挡关系 |
| aged-academia | 研究历史、知识演进、档案质感 | 纸张与墨色服务阅读，不制造不存在的古籍或原始证据 |
| knolling | 工具集合、组成要素、并列比较 | 对齐呈现确有意义的对象，避免堆满装饰物 |
| minimal-monolith | 单一概念、核心变化、强主次 | 一个清楚主体，充足留白，减少无信息元素 |
| signal-aurora | 信号、连接、未来感概念 | 控制光效与色相，不用霓虹渐变代替解释 |
| warm-editorial | 生活场景、温暖的编辑插图 | 具体而克制，人物与场景不冒充真实用户经历 |

原创微信封面遵循当前默认规格：47:20、印象派水墨、无文字/Logo/人物，至多三类主色；用户的明确要求可调整。正文解释图保留必要标签、坐标和图例。不要按图片序号强制更换风格、温度或工具，也不预设每篇图数。

真实提示词写清对象、解释目标、构图、比例、风格与约束。生成后查看图片，按正文用途检查细节和可读性；仅有风格词或提示词不构成完成。
